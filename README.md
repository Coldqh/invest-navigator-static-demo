# Invest Navigator AI — Static Demo

**Invest Navigator AI** — демо-версия инвестиционного веб-приложения для анализа активов, симуляции портфеля и работы с AI-отчётами.

Проект изначально развивался как fullstack-приложение на Java + Spring Boot + PostgreSQL, но эта версия адаптирована под **GitHub Pages** и работает полностью в браузере.

## Live Demo

https://coldqh.github.io/invest-navigator-static-demo/

## Что умеет приложение

### Dashboard

Главный экран с рыночной сводкой:

- наибольший рост;
- наибольшее падение;
- максимальная волатильность;
- максимальный риск;
- максимальный объём;
- самый дорогой актив;
- самый дешёвый актив;
- рыночная ширина;
- сигналы рынка;
- топы по росту, падению, риску, волатильности, объёму и цене.

### Активы

Страница списка активов:

- акции;
- криптовалюты;
- поиск;
- фильтрация;
- сортировка;
- цена;
- риск;
- волатильность;
- объём;
- источник данных.

### Страница актива

Детальная карточка актива:

- текущая цена;
- изменение;
- риск;
- волатильность;
- средний объём;
- источник данных;
- график;
- режимы графика:
  - день;
  - неделя;
  - месяц;
- режимы отображения:
  - линия;
  - свечи;
- tooltip при наведении;
- AI-анализ актива.

### Сравнение

Сравнение любых двух активов:

- рост;
- риск;
- волатильность;
- объём;
- цена;
- победитель по каждой категории.

### Портфель

Браузерный симулятор инвестиций:

- счёт в RUB;
- счёт в USD;
- покупка активов;
- продажа лотов;
- автоматический расчёт суммы покупки;
- автоматический расчёт суммы продажи;
- открытые позиции;
- отдельные лоты;
- точное время покупки;
- закрытые сделки;
- реализованный PnL;
- нереализованный PnL;
- лучший и худший трейд;
- последние операции;
- AI-анализ портфеля.

### Данные

Экспорт и импорт данных:

- скачать JSON backup;
- скопировать JSON backup;
- загрузить JSON backup;
- вставить JSON backup вручную;
- перенести портфель между браузерами, ПК и телефоном.

## Источники данных

Приложение работает без backend, поэтому данные берутся прямо из браузера.

### Binance

Используется для криптовалют.

Пример:

- BTCUSDT;
- ETHUSDT;
- BNBUSDT.

### MOEX

Используется для российских акций через публичный ISS API Московской биржи.

Пример:

- SBER;
- LKOH;
- MGNT;
- ROSN;
- VTBR;
- YDEX.

### DEMO fallback

Если внешний источник недоступен, приложение использует demo fallback, чтобы интерфейс продолжал работать.

## AI

В проекте есть AI-отчёты:

- по отдельному активу;
- по портфелю.

AI-отчёт формирует:

- краткий вердикт;
- summary;
- сильные стороны;
- слабые места;
- пункты для проверки;
- риск.

AI-блок не является инвестиционной рекомендацией.

---

## Хранение данных

В static-версии нет базы данных.

Все пользовательские данные хранятся в браузере через `localStorage`:

- баланс RUB/USD;
- открытые лоты;
- операции;
- закрытые сделки;
- импортированные данные.

Для переноса данных используется страница **Данные**.
